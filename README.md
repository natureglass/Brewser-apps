# Brewser Apps

The **published app catalogue** for [Brewser](https://brewser.io) — the homebrew app hub and runtime for Nintendo Switch that lets people build and run apps made with everyday web technologies like HTML, CSS, JavaScript, WebGL, and WASM.

Everything in this repository is **live**. If an app is here, it has been published: **Brewser Runtime** on the Switch downloads apps straight from this repository and runs them locally on the console. On the web, the same apps are hosted from this repo via GitHub Pages (**play.brewser.io**) and run embedded in the catalogue at **[brewser.io](https://brewser.io)**.

---

## What lives here

This is the final home for published apps — the demos, tools, games, and experiments that have made it through automated security scanning (static analysis and taint tracking), review, and staging, and gone public. When you browse the catalogue inside Brewser Runtime and download an app, this is where it comes from — and it runs locally on your console from there.

Apps arrive here **after** they've been tested in staging and approved. Before that, they live in the [Brewser Apps Staging](https://github.com/natureglass/Brewser-apps-staging) repository, where signed-in users can try them on real hardware first.

---

## Want to publish your own app?

App publishing happens through the **[brewser.io](https://brewser.io/submit/)** website. Sign in, submit your app, and once it's approved it lands here automatically.
