# Cracktro Forever

_v1.0.3_

A procedural tribute to the classic Amiga cracktro and demoscene, built for the Switch homebrew community.

It has the usual old-school parts: a sine-wave scroller, copper bars, plasma, a 3D starfield, a raster-bounced logo, and a chiptune soundtrack that the effects run to. Everything is generated at runtime from code. No textures, no pre-rendered graphics, no external assets. The geometry comes from math and the visuals from shaders, all in a single HTML file.

Effects fade in and out with the music so it plays as one continuous intro.
