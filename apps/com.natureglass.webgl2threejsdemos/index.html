WebGL 2 — Three.js Demos

Production demos exercising canvas.getContext('webgl2') + GLSL ES 3.00 shaders + WebGL 2-specific surface (MRT, UBOs, etc.). Each entry exercises a different part of the GL render path. Pick one to launch it.

  • gtlf Loader
    Exercises GPUComputationRenderer: ping-pong float RTs drive a 128×128 heightfield fluid sim; the MeshStandardMaterial samples that heightmap in its vertex shader for displacement + reconstructed normals.
  • loader / collada
    Exercises GPUComputationRenderer: ping-pong float RTs drive a 128×128 heightfield fluid sim; the MeshStandardMaterial samples that heightmap in its vertex shader for displacement + reconstructed normals.
  • GPGPU Water
    Exercises GPUComputationRenderer: ping-pong float RTs drive a 128×128 heightfield fluid sim; the MeshStandardMaterial samples that heightmap in its vertex shader for displacement + reconstructed normals.
  • Dynamic Cubemap Reflection
    Exercises CubeCamera: 6× perspective renders per frame populate a 128px-per-face WebGLCubeRenderTarget. A reflective sphere sources its envMap from the cube target so its surface mirrors the orbiting bodies in real time.
  • Equirect Env Reflection (Phong)
    Exercises Three.js's classic non-PMREM ENVMAP_TYPE_EQUIREC fragment chunk: a TorusKnot with MeshPhongMaterial samples an equirectangular LDR JPG directly as its envMap. (PMREMGenerator hard-crashes the bridge; this is the working subset.)
  • Dynamic Instancing
    Exercises InstancedMesh with DynamicDrawUsage: per-instance matrix + per-instance color uploaded every frame for a wave-of-cubes oscillation. 196 instances through a single drawElementsInstanced call.
  • Selective Unreal Bloom
    Exercises two chained EffectComposers (selective via Layers + material swap), UnrealBloomPass's 13-quad mip-blur chain, and a custom ShaderPass compositor through the WebGL2 bridge.
  • Spotlight + Shadow + Cookie
    Exercises Three.js's PCF shadow render pass and spotLight.map (cookie-projected light) sampler through the WebGL2 bridge.
  • Post-processing Pixelation
    Exercises EffectComposer, DepthTexture sampling, and scene.overrideMaterial via RenderPixelatedPass (low-res beauty FBO + normal pass + depth/normal edge detect) through the WebGL2 bridge.
  • Rapier3d Physics
    Exercises the WASM bridge alongside the WebGL2 render path — Rapier3d rigid-body physics simulating random shapes falling onto a static floor with restitution.
  • Uniform Buffer Objects
    Exercises the GL_UNIFORM_BUFFER path (bindBufferRange + uniform block binding) with two meshes sharing camera + lighting state via a single UBO.
  • Multiple Render Targets
    Exercises MRT via WEBGL_draw_buffers — geometry rendered into multiple FBO attachments simultaneously, G-buffer style (albedo / normal / depth).
  • Texture 2D Array
    Exercises sampler2DArray uniforms — a volumetric brain MRI rendered as slices through a Texture2DArray with the active slice index animated each frame.
  • Shaders: Sky
    Exercises a long custom atmospheric-sky shader through the bridge with multiple float uniforms (sun azimuth + elevation) updated each frame.
  • Materials: Video Texture
    Exercises the bridge's per-frame DataTexture re-upload path: a Switch.VideoDecoder instance (NVTEGRA NVDEC hw-accel) feeds the Sintel trailer's RGBA frames into a shared map, mosaiced across a 200-cube grid. Postprocessing chain adds a gaussian BloomPass + OutputPass.
  • Textured Rotating Cube
    A 1x1x1 BoxGeometry rotated each frame and textured with a crate image. First milestone exercising runtime image upload through the new texImage2D + Image() pipeline.
