Vertical margin collapsing (new)

CSS 2.1 §8.3.1. Each case shows the actual collapsing structure beside a reference built to the already-collapsed result. PASS = the two columns look identical (same gaps, same slate bands). The slate background reveals gaps; the thin outline marks each parent box. This engine uses a contained model — a collapsed child margin does not become the parent's own outer margin.

1 · Adjacent siblings — positive (parent padded, edges closed)

margin-bottom:40 then margin-top:20 collapse to 40 (the max), not 60. Parent padding closes the top/bottom edges so only the sibling gap is under test.
