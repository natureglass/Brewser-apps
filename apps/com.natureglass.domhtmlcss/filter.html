CSS filter

Every tile is the same gradient element under a different filter. Cairo has no native ctx.filter, so each is computed by rendering the element to an offscreen and processing its pixels — a fused colour matrix (brightness / contrast / grayscale / sepia / invert / saturate / hue-rotate / opacity), a premultiplied box blur, and drop-shadow via native shadow-blur.
