The video element

Coverage matrix for the <video> element's container + codec paths. Each block points at a different file under sdmc:/switch/brewser/dev/assets/. Tap the play / pause / stop buttons on a video's controls bar to interact with it; tap the video frame itself to reveal the controls bar.

Nothing autoplays; tap a video's ▶ button to open its decoder and start playback. To test the display transform: play a video, then tap the frame once to pause (the control bar appears) and tap the gear (left of the speaker) — a pop-up opens with Aspect / Zoom / Crop. Double-tap the frame to enter fullscreen (B exits).

1. mp4 — H.264 + AAC

Container: ISO BMFF (mp4) · Video: H.264 · Audio: AAC · Baseline (was the slice-2b reference fixture).

2. mov — H.264 + AAC (QuickTime container)

Container: QuickTime (mov) · Video: H.264 · Audio: AAC · Exercises the QuickTime demuxer with the same codecs as mp4.

3. mkv — H.264 + Vorbis (Matroska container)

Container: Matroska (mkv) · Video: H.264 · Audio: Vorbis · First Vorbis audio decoder + first mkv demuxer in the coverage set.

4. webm — VP8 + Vorbis

Container: WebM (Matroska) · Video: VP8 · Audio: Vorbis · First VP8 video decoder (software-only, Tegra NVDEC is H.264-only).

5. m4a — AAC audio only

Container: ISO BMFF (M4A) · Video: none · Audio: AAC · Audio-only file in a <video> element — uses the usedVideo=false path; placeholder stays visible while audio plays.

6. mp3 — MP3 audio only

Container: MP3 with ID3v2 tag · Video: none · Audio: MP3 · First MP3 demuxer + first MP3 decoder in the coverage set.

7. wav — PCM 16-bit stereo 48 kHz audio only

Container: RIFF/WAVE · Video: none · Audio: PCM s16le · Uncompressed audio through the swresample stage.

8. flac — FLAC audio only

Container: native FLAC · Video: none · Audio: FLAC · First FLAC demuxer + FLAC decoder in the coverage set.

9. opus — Opus audio only

Container: Ogg · Video: none · Audio: Opus · First Opus decoder + Ogg demuxer in the coverage set.

10. ogg — Vorbis audio only (Ogg container)

Container: Ogg · Video: none · Audio: Vorbis · Vorbis through Ogg vs. Vorbis through Matroska (block 3) — isolates demuxer effects from codec effects.
