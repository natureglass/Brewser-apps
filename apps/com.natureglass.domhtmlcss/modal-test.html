Modal layer — stress test

Exercises native <dialog> + engine-blessed <browser-modal> + edge cases (image race, CSS animation, focus, multiple modals, stress).

A. Native <dialog> — basic show / close

Spec-shaped API: dialog.showModal() / dialog.close('value'). Listens for the close event + reads returnValue.

Basic dialog

Press a button to close. Each emits a different returnValue.

B. Native <dialog> — image inside (logo race)

Opens a dialog with an <img> whose src is set at open time. Close before/after the image loads — the host cache must not bake the logo in (this was the original ghost bug).

Image-bearing dialog

This logo loads asynchronously. Close fast to verify there's no ghost left behind.

C. Native <dialog> — CSS animation inside

Loading-bar pulse animation runs while the dialog is open. Closing should stop visible repaint of the host area (the bar may keep ticking off-screen but must not bake into the host cache).

Animated dialog

Pulsing yellow bar above. Close and watch the page underneath stay clean.

D. Native <dialog> — input + focus

Tap the input to open the on-canvas keyboard. The dialog stays alive while the keyboard is up. Confirm reads the value into the close returnValue.
