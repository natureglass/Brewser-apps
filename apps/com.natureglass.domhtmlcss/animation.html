CSS @keyframes animation (new)

All demos run automatically (no interaction - Switch has no hover). Before this milestone only rotate / scale / opacity interpolated; translate, colour, animation-delay, and animation-direction are new. Timing functions (ease / cubic-bezier / steps) were already wired.

Control · rotate (unchanged)

Continuous spin - the pre-existing rotate path, here as a baseline.

spin

1 · translate X - px, alternate

Slides right 200px then back (direction reverses each iteration). Motion + reversal are both new.

px

2 · translate X - percent (translateX(-100%) -> 0)

Percent translate resolves against the box's own width - slides fully out to the left and back in.

%

3 · translate Y bob - ease-in-out alternate

Bounces up 30px and settles, easing at each end.

bob

4 · background-color pulse (colour interpolation)

Interpolates blue <-> pink each iteration - @keyframes colour animation is new (only transitions did colour before).

flash

5 · animation-delay - staggered loading dots

Same 1.2s pulse, delays 0 / 0.2s / 0.4s - they ripple in sequence. The delay was previously dropped.

6 · timing functions on the same translate

Both slide 210px over 1.8s: top is linear (constant speed), bottom is ease-in-out (slow-fast-slow). They should visibly diverge mid-travel and meet at the ends.
