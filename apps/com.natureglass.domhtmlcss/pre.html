Preformatted text & white-space

1 · <pre> (UA white-space: pre)

Preserves whitespace, newlines, and indentation; monospace; no wrapping.

function greet(name) {
    if (!name) {
        return "hello, friend";
    }
    return "hello, " + name + "!";
}

3 · white-space: pre on a <div>

Same preservation as <pre> but on a plain element; long lines do NOT wrap (they overflow the box):

a b c indented line no-wrap: this long line keeps going past the right edge instead of wrapping.

4 · white-space: pre via a STYLESHEET CLASS (new)

Same content as §3 but the rule comes from .classpre { white-space: pre } in the page stylesheet, not an inline style=. Before this fix the parser collapsed the whitespace before the cascade was known, so class-driven preservation did nothing. It must now match §3 exactly:

a b c indented line no-wrap: this long line keeps going past the right edge instead of wrapping.

5 · white-space: pre-line (new)

Collapses runs of spaces to one, BUT keeps explicit newlines as breaks, AND wraps long lines. The triple spaces below collapse; the three short lines stay on three lines; the long paragraph wraps:

alpha beta gamma line two line three this long physical line has no newline of its own but should still wrap at the 360px box edge because pre-line wraps like normal text.
