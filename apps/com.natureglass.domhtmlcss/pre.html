Preformatted text & white-space

1 · <pre> (UA white-space: pre)

Preserves whitespace, newlines, and indentation; monospace; no wrapping.

function greet(name) {
    if (!name) {
        return "hello, friend";
    }
    return "hello, " + name + "!";
}

Same preservation as <pre> but on a plain element; long lines do NOT wrap (they overflow the box):

a b c indented line no-wrap: this long line keeps going past the right edge instead of wrapping.
