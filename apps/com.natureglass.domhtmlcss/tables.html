Single-column wide content

Long-running notes
A single column gets the entire table content width. Text inside wraps at the column edge using the same inline-flow path as paragraphs outside the table. Multi-sentence content fits without horizontal overflow.
Second row inherits the same column width.

colspan

Cells with colspan stretch across multiple columns and push the following cells right. Borders make the merges obvious.

Cells with rowspan extend down over later rows; the other cells in those rows flow into the remaining columns.
