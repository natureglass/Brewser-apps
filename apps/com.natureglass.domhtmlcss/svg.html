Stroke styling: dash / linecap / linejoin / opacity

Exercises the newer paint attributes on the same render path.

text / tspan

SVG <text> now renders: font size/family/weight/style, fill + stroke, text-anchor, dominant-baseline, and per-<tspan> positioning. A small red dot marks each (x, y) anchor point.

gradients: linear + radial

SVG <linearGradient> / <radialGradient> referenced via fill="url(#id)" now render — colour stops, objectBoundingBox (default) + userSpaceOnUse units, and xlink:href stop inheritance. Also works on stroke and text.
