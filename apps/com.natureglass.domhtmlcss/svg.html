Stroke styling: dash / linecap / linejoin / opacity

Exercises the newer paint attributes on the same render path.

text / tspan

SVG <text> now renders: font size/family/weight/style, fill + stroke, text-anchor, dominant-baseline, and per-<tspan> positioning. A small red dot marks each (x, y) anchor point.

gradients: linear + radial

SVG <linearGradient> / <radialGradient> referenced via fill="url(#id)" now render — colour stops, objectBoundingBox (default) + userSpaceOnUse units, and xlink:href stop inheritance. Also works on stroke and text.

<image>

SVG <image> decodes via the same loader as <img> (local file, works offline). The yellow border is the image's x/y/width/height box; preserveAspectRatio controls the fit inside it.

meet (fit, letterboxed) · slice (cover, cropped) · none (stretched).

<pattern>

Tiled paint servers via fill="url(#id)". objectBoundingBox units (dots, cell = fraction of the shape) and userSpaceOnUse (stripes, cell in absolute units).

<marker>

marker-start/-mid/-end on line, polyline and path. Arrowheads use orient="auto" (rotate to the path direction); dots don't. markerUnits defaults to strokeWidth, so markers scale with the stroke.

<mask>

Luminance mask: a black→white gradient in the mask makes the blue slab fade from transparent (left) to opaque (right). The green slab is masked by a circle (opaque disc, transparent outside).

<filter>

Offscreen pixel filters. Each cell shows a faint reference (unfiltered) and the filtered copy. Supported subset: feGaussianBlur, feColorMatrix (saturate / hueRotate / matrix), feDropShadow. A filter using any unsupported primitive falls back to an unfiltered paint (never blanks).

blur · saturate 0 (greyscale) · hueRotate 120° · drop-shadow.
