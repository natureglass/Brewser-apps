CSS cascade & layout

  • css
    Cascade, specificity, inline styles, and the box model.
  • external-css
    Stylesheet loaded via <link rel="stylesheet">.
  • inherit
    Font-size and color inheritance down the tree.
  • selectors
    Type, class, id, descendant, and pseudo-class matching.
  • align
    Horizontal alignment via text-align.
  • display-none
    Hiding elements with display: none.
  • border
    Borders with mixed widths, styles, and per-side colors.
  • border-styles
    Non-solid border-style: dashed, dotted, double, and the 3D styles (groove / ridge / inset / outset), mixed per-side, rounded non-solid borders, and outline (with outline-offset) painted outside the box.
  • rounded
    Rounded boxes and clipping via border-radius, including per-corner radii (longhands + 1–4-value shorthand) on backgrounds and borders.
  • cursors
    Different cursor types.
  • sticky
    position: sticky — a top: 0 bar that pins while scrolling, section headings that pin then release at their section end, and a bottom: 0 footnote. Bar button proves hit-testing at the pinned position.
  • flex-wrap
    flex-wrap multi-line flexbox: wrapping rows, align-content, per-item align-self, justify-content: space-evenly, and flex-flow: row wrap-reverse.
  • grid
    Grid depth: grid-template-areas (app shell), auto-fill tracks, per-item justify-self/align-self, grid-auto-rows, track distribution via justify-content, and independent row-gap/column-gap.
  • transition
    transition animates value changes: background-color, opacity, transform (scale), text color, border-color, a multi-property list with cubic-bezier, and a linear-vs-ease-in-out comparison. Tap-toggle driven; reverses mid-flight.
  • filter
    filter on element content: blur, brightness/contrast/grayscale/sepia/invert/saturate/hue-rotate/opacity, drop-shadow, and combinations — computed by offscreen pixel processing (no native ctx.filter). Plus a dynamic tap-toggle.
  • backdrop-filter
    backdrop-filter frosted glass: a sticky bar and a fixed pill that blur the scrolling content behind them, plus normal-flow cards that frost a colourful panel. Backdrop read from the body cache (not the Skia screen), reusing the filter pixel core; rounded-corner clip.
