# Turbo arena

_v1.0.3_

Turbo Arena 4.0 — Nintendo Switch / Brewser Edition

 

 Turbo Arena 4.0 is a 3D arcade driving game built with HTML5 and WebGL. This version is designed for widescreen gameplay and supports touchscreen input and Nintendo Switch game controllers.

 

 Controls

 

 - Left stick: Drive and steer

 - Right stick: Camera

 - A: Jump

 - B: Brake

 - Y: Drift

 - R: Nitro

 

 Features: Fullscreen gameplay, responsive menus, adjustable touch controls, and controller support.

 

 Compatibility: Designed for Brewser Runtime. Performance and input compatibility require testing on the target device.

 

 Credits: Original Turbo Arena 4.0 project. Third-party libraries and assets remain subject to their respective licenses.
